# AgriSage AI — Datasets Directory

This directory stores datasets utilized for crop recommendation, yield prediction, market prices, and demo fallbacks.

## Guidelines
- In accordance with the **Honesty Rules**, datasets larger than 20 MB must NEVER be committed to Git.
- Large raw datasets should be downloaded locally using `scripts/` or kept in external persistent storage.
- Labelled offline demo fallbacks are stored in `datasets/demo/`.
- Every dataset placed in this folder must have its license, source URL, and terms verified before training production models.
